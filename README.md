# Sales Data Analysis – Power BI

## Overview

This project is a Sales Data Analysis dashboard created using Microsoft Power BI as part of my Data Analytics learning journey.

The project was completed as a guided project from the Complete Data Analyst Bootcamp by Krish Naik.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX

## Project Objective

The objective of this project is to analyze sales data and build an interactive Power BI dashboard that provides insights into sales, profit, quantity sold, discounts, orders, products, customers, and geographical performance.

## Key Analysis & Dashboard Features

The dashboard provides the following analyses and interactive visualizations:

### 1. Top and Bottom Performing Products

- Identifies the top 5 and bottom 5 products based on:
  - Sales
  - Profit
  - Quantity Sold

### 2. Sales Trend Analysis

- Analyzes how sales vary over time.
- Provides daily, monthly, quarterly, and annual views of sales performance.

### 3. Sales and Profit Relationship

- Visualizes the relationship between sales and profit.
- Helps understand how changes in sales correspond to profitability.

### 4. Period Comparison

- Allows users to select and compare two different time periods.
- Compares:
  - Sales
  - Profit
  - Quantity Sold

### 5. Average Discount by Product Category

- Shows the average discount offered across different product categories.
- Helps compare discount patterns between categories.

### 6. Total Number of Orders

- Displays the overall number of orders.
- The metric can be explored using the available dashboard filters.

### 7. Detailed Order-Level Analysis

The dashboard provides detailed information for individual orders, including:

- Sales
- Profit
- Discount
- Net Sales
- Product-related information
- Customer-related information
- Order-related information

The data can be interactively filtered using parameters such as:

- Product
- Date
- Customer ID
- Customer Category
- Other available fields

### 8. Geographical Sales Analysis

- Visualizes sales across different cities.
- Helps identify geographical differences in sales performance.

## Dashboard

The project includes an interactive Power BI dashboard that allows users to explore the sales data using different visualizations, filters, and time-period selections.
